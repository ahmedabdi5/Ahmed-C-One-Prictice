

Project Title: Electricity Bill Calculator

Introduction

This project is an Electricity Bill Calculator developed using C# Windows Forms. It is designed to calculate the total electricity bill based on the units consumed and the price per unit.

Project Description

The application allows users to enter customer information, electricity units consumed, and the price per unit. It calculates the total bill and displays the result on the screen.

Objectives

- To develop a Windows Forms application using C#.
- To understand how to use TextBoxes, Labels, and Buttons.
- To practice variables and data types.
- To perform mathematical calculations.
- To use event handling in C#.
- To display calculation results using MessageBox and Labels.

Features

- Enter customer name.
- Enter electricity units consumed.
- Enter price per unit.
- Calculate the total electricity bill.
- Display the customer's name and total bill.
- Clear all entered information.

Technologies Used

- C# Programming Language
- Visual Studio
- Windows Forms Application

Conclusion

This project helped me improve my knowledge of C# programming and Windows Forms applications. I learned how to accept user input, perform calculations, display results, and handle button click events.
