# C# MessageBox

## Description

This project demonstrates how to use `MessageBox.Show()` in C# Windows Forms to display a pop-up message when a button is clicked.

## Code

```csharp
MessageBox.Show("Hello World");
```

## Explanation

* `MessageBox.Show()` is a built-in C# method used to display a message in a pop-up window.
* `"Hello World"` is the text displayed inside the message box.
* The message box appears when the user clicks the button.

## Output

When the button is clicked, a pop-up window displays:
**Hello World**



# C# – Close Form

## Description

This project demonstrates how to close the current Windows Form using the `this.Close()` method in C#.

## Code

```csharp
this.Close();
```

## Explanation

* `this` refers to the current form.
* `Close()` is a method used to close the current form.
* When this code is executed, the current window will close.

## Usage

This code is commonly used in an Exit button to close a Windows Forms application.
